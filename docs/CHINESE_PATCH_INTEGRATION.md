# 语言资源接入

服务端只实现语言选择、覆盖层校验与 HTTP 分发；二进制补丁和客户端构建工具由独立配套包提供，不提交本仓库。

默认日语。服务目录包含 `patches/ja-JP/manifest.json` 时使用日语恢复层；否则使用自己的原始日语资源档案。中文需要完整的 `patches/zh-Hans`，启动时缺失或校验失败会停止。一个服务进程统一使用所选语言。

## 覆盖清单

`patches/<locale>/manifest.json` 使用 schema 1、client_version_code 5465，以及相对缓存路径、大小和 SHA-256。禁止开发机绝对路径、路径穿越、符号链接及重复目标。

当前配套中文包包含四个必要目标：主数据 Bundle、字体 Bundle、加密游戏 Manifest 的 `__data`、加密缓存数据库 `Android/bundle/db`。游戏 CRC 必须与 Bundle 解压后的 UnityFS 数据流一致。只修改主数据和字体而未同步两个清单，会导致游戏删除补丁文件或拒绝加载。

服务端把覆盖项加入 `/bootstrap/manifest.json`，通过整套文件 revision 驱动客户端检查。覆盖项额外标记 `startup_check: true`，支持新版客户端在快速启动时校验这些关键缓存；该字段不能替代实际客户端实现。原游戏 CDN 与启动下载器必须返回相同字节。

切换语言前退出客户端，重启服务端选择语言，再打开客户端。日语恢复层应覆盖与中文相同的四个目标，以恢复缓存 CRC，而不是只换回主数据 Bundle。

## 范围与验收

第一批交付译文为 1,822 条界面文本、164 条角色名和 11 条声优资料，未覆盖全部剧情、任务、称号、图片或 IL2CPP 常量。字体源文件替换也不等于所有 TMP 字形、图集和排版已经适配。

传输哈希、清单 CRC、实际启动、中文显示和冷重启需要分别验收。当前结果以 [验证记录](VALIDATION.md) 为准；默认日语保持不变。字体包需随附其 Noto Sans CJK / OFL 许可。
