## 服务端与存档

- 当前服务端测试 29 项通过。覆盖资源白名单、SHA-256、Range / If-Range、路径约束、文件变化拒绝、默认日语与语言参数、诊断接口关闭、迁移与独立部署。
- 独立测试把服务端复制到临时新目录：没有旧服务端、客户端构建工具或语言包，使用自有测试资源完成 API、资源清单、下载与安装页检查。所有运行路径位于新目录中。
- 默认资源根目录为本机 `resources/`，不再回退读取父目录。服务端启动不依赖 APK 模板、Java、ADB 或旧证书。
- 旧库实际副本迁移：7,466 条玩家记录逐表对比一致，源数据库 SHA-256 未变化。另用合成存档验证了缺少较新升级标记时仍保留玩家经验、卡片和成绩，重启不重置。
- 目标已有存档时默认拒绝替换；显式替换会创建经校验的目标备份。运行中的新版服务与迁移工具使用互斥锁。
- 指定的旧账号 ID 保存在数据库，验证了不同安装 UUID 登录仍读取选定的原账号与经验值。
- 当前 Git 索引共 1,235 个服务端 / 数据文件，约 8 MiB。隐私检查通过，无 APK、语言二进制补丁、运行环境、个人 SQLite 库或签名材料。

## 配套客户端与中文实验

此前 ARM64 LAN 客户端在无 root Android 17 / 4 KiB 平板经局域网下载 APK 和 7,408 个资源，进入过主页并产生歌曲开始请求。早期基线另有 Android 14、16 的启动测试或用户确认。它仍为 Unity 2018.4.18f1，并非完整工程升级，未覆盖全部机型、16 KiB 页或所有游戏功能。

2026-09-13 在 Android 14 模拟器复现中文主数据被删除：游戏 Manifest 的 CRC 已更新，但本地 `Android/bundle/db` 仍记录旧日语 CRC。配套补丁已同步主数据、字体、加密游戏 Manifest、加密缓存数据库四项；日语保留对应恢复层。中文实际显示与冷启动验收仍在继续，不能仅凭文件校验宣称完整汉化可用。
