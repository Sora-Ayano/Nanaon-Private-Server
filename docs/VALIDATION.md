# 验证记录

更新：2026-10-03。公开记录不附设备序列号、本机地址、账号恢复码、个人存档、截图或原始日志。

## 服务端与存档

- 当前服务端测试 55 项通过。覆盖独立部署、存档迁移、语言选择、资源白名单、SHA-256、Range / If-Range、变化文件拒绝、云端账号隔离与并发创建、抽卡、商店、换装、主推成员、家具布局、展示室和增量包。
- 独立部署测试将服务端复制到临时新目录。局域网实例只使用新目录的自有测试资源；云端实例没有 APK、完整资源、语言包、客户端构建工具或旧服务端，仍可创建账号并处理 API。
- 云端使用独立数据库与随机账号凭证的摘要绑定。相同原游戏 UUID 的不同玩家不会共享账号；缺少凭证、未知凭证和冒用其他玩家 ID 的请求被拒绝。并发首次登录、服务重启、资料编辑、抽卡和商店购买均有隔离测试。
- 设置接口只修改指定设置，不能通过请求中的 `id` 或经验字段改写另一个账号。旧本地账号可以在停服后显式绑定恢复码，已有绑定不覆盖。
- 对全部 144 个恢复卡池逐池抽取，核对奖励并重启数据库；包含 383 个价格选项、抽卡券、付费宝石、保底组、重复卡突破上限及每日日本时间 04:00 重置。十连同一卡多次突破合并为一项通知，避免客户端重复字典键异常。
- 三项主数据商店商品使用真实价格与奖励。购买扣费、奖励、次数和流水在同一事务内提交；写入失败、余额不足或体力已满不会留下扣费。体力恢复上限为 99。
- 换装、主推成员和已觉醒插图选择可保存并在重启后恢复。空家具布局自动补齐；已有非空布局保留，家具等级限制来自主数据。
- 旧库实际副本迁移此前核对过 7,466 条玩家记录，源数据库 SHA-256 未变化。合成旧结构测试验证经验、卡片和成绩不会因缺少较新升级标记而重置。目标已有存档默认拒绝替换，显式替换先创建一致性备份。
- 服务端运行路径默认位于自身目录，不回退读取父目录或旧服务端；云端没有完整资源 CDN。诊断接口和流量落盘默认关闭。

## 新版客户端实际操作

本轮在 Android 9 的雷电模拟器上安装并测试新版 LAN 客户端，使用测试存档。模拟器有 root；安装、局域网下载和游戏运行流程没有使用 root 或 USB 资源推送。未改动正式玩家数据库。

| 操作 | 本轮结果 |
| --- | --- |
| 下载页选择本地或手动云地址 | 已接入；首次默认为本地，之后保留上次选择 |
| 云端登录且本地资源服务关闭 | 进入主页，家具与角色显示；资源读取设备内的已校验副本 |
| 真实增量更新 | 先完成 1,490 个文件约 139 MiB，再完成 265 个文件约 106 MiB；本地资源服务关闭，更新后进入游戏 |
| 抽卡 | 多卡池页面显示；实际十连完成动画与十张结果页，扣费、重复卡奖励写入测试账号 |
| 2D 换装 | 可进入角色与服装列表，显示真实模型，保存新服装并返回成员页 |
| 主推成员 | 更换角色和卡面，页面显示设置完成，数据库保存对应主数据 ID |
| 地图与展示室 | 地图可滚动、展示室可进入，角色和家具显示并响应操作 |
| 宝石恢复体力 | 确认页面完成购买，扣除 50 宝石、体力增加 3，画面与数据库一致 |
| 中文 | 本轮登录、角色名称、下载确认、抽卡结果、换装、主推成员与购买提示未再看到缺字方框；未宣称完整汉化 |

资源保护副本与原游戏自身缓存分开；游戏清理自己的缓存后仍能从设备内重建。启动前同步游戏 Manifest 与缓存数据库，解决固定 asset version 下继续使用旧 CRC 的问题。恢复的抽卡图片具有独立 AssetBundle 内部名称，避免多个模板副本同时加载时冲突。

## 仍需验收的范围

- 主数据列出 483 套 2D 衣服，目前 359 套有完整模型、依赖和图标，另外 124 套缺少真实资源。部分同一服装的缺失角度预览使用该服装已有正面模型；这不等于补回原角度。
- 264 张补齐抽卡图片中，7 张来自保留的原图，其他使用注明“保存版 / 復元表示”的文字图。完整初始资源清单为 8,896 项，仍有一个未找到的兼容脚本；不能据此宣称所有剧情、影片或活动都完整可用。
- 原游戏过期抽卡兑换、真实付费、多人联机和部分活动仍有兼容空响应或保存模式简化逻辑。未完成全部页面、全部服装、全部剧情与长期游玩验收。
- 云端是在本机独立端口做功能验证，尚未部署到实际公网主机；公网域名、HTTPS 反向代理、并发容量和备份恢复应在部署后验收。
- 此前 ARM64 LAN 基线在无 root Android 17 / 4 KiB 页平板通过局域网下载完整资源并进入主页，另有 Android 14、16 的启动测试或用户确认。**本轮新增服务器选择的 APK 尚未重新验收 Android 14 / 16 / 17。** 基线仍为 Unity 2018.4.18f1 / IL2CPP，未覆盖 16 KiB 页设备和所有机型。

## 发布边界

GitHub main 仅包含服务端源码、静态 JSON 数据、数据库结构、必要兼容资源、工具和文档。发布前检查 Git 索引中的实际内容，排除 APK、完整游戏档案、中文二进制包、运行依赖、真实 SQLite 存档、账号凭证、签名材料与本机标识。
